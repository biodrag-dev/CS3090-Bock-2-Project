A basic program that does a very simple job of encryption.
The encryption simply shifts the characters by a random amount, and then decrypts it in the same way of shifting it back. 


Running the program can be done in anything that runs Java, I used IntelliJ IDEA Ultimate.
No dependencies are needed, as it's rather simple.

This tool is for educational use only, and should not be used for real-world encryption. The encryption itself is nothing more than a basic character shift, and could be cracked easily.

Ethical Considerations:
- It could be cracked very easily, especially with the same code that encrypted it. This would be terrible if someone actually used it for their passwords, since it would give a false sense of security.
- If the encryption was more advanced, it could potentially be misused by hiding malicious data (ie. malware) or ransomware.

Encryption itself isn't necessarily malicious, since it's used for protecting stored data and respecting privacy. However, it can be misused in those ways.
